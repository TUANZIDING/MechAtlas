# 证据分级指南 · Grading guide（v0.1）

**核心：** 等级回答"这条关系是在多像目标课题的模型里测到的"，`causal` 回答"有没有做过因果检验"，`abstract_only` 回答"我们读到多深"。三者分开记录，不要混成一个分数。

## 默认 A / B / C

| 等级 | 定义 | 典型情形 | 不能这样用 |
|---|---|---|---|
| **A** | 目标课题的直接模型 | 辐射课题：照射骨骼肌或肌源细胞，在该模型中测得该关系，报告剂量与时间点 | 仅摘要不能评 A；A 级必须读全文 |
| **B** | 邻近/非目标模型，或条件性、摘要级 | 其他损伤模型（CTX、缺血、mdx）；辐射模型但结果依赖剂量/时相/合并因素；会议摘要 | 不能拿 B 级外推成"辐射也如此" |
| **C** | 推断、候选、间接 | 生信预测靶点；肿瘤外泌体介导的远隔效应；仅 mRNA 改变推断通路活性；只有体外且模型偏离较远 | 只用于提出假说 |
| **骨架** | 方向矛盾或只有假说 | Myostatin（mRNA↓ 而蛋白↑）；cGAS–STING（0 篇）；"在体辐射 + 外源 EV + 功能终点"（0 篇） | 不连证据边，不下结论 |

每个课题可以在 YAML 的 `grades:` 里改写定义（例如 EV 课题把 B 定义为"非辐射损伤模型的在体 EV 干预"，C 为"仅体外/摘要级/候选"）。字母 A/B/C 保持不变，图谱与脚本按字母工作。

## 其他字段

- **`causal`**：只有做过因果检验才为 `true`——基因敲除/敲低、抑制剂或激动剂、挽救实验、antagomiR、中和抗体、外源给药并有对照。仅相关或前后比较一律 `false`，报告中标【关联】。
- **`abstract_only`**：只读到摘要（会议摘要、拿不到全文）。最高 B 级，来源卡显示"仅摘要"。
- **`direction`**：`+` 增加/激活，`−` 减少/抑制（图上画成横杠）。方向依条件而变（如 IL-6 在成肌细胞↓、组织/血清↑）时，拆成两条带不同模型的边，或画骨架节点。
- **`limitation`**：一句话写清这条证据不能说明什么（"纯体外；无在体、无功能学终点"）。

## 事实 / 关联 / 推测（报告用语）

| 标签 | 含义 | 例句 |
|---|---|---|
| 【事实】 | 原文在该模型中直接测得 | 非照射 MPC-EV 使受照 MPC 活力由 52% 升至 71%（PMID 40835994，体外） |
| 【关联】 | 相关或单项比较，未做因果检验 | 照射后 FBXO32 上调与肌萎缩同时出现 |
| 【推测】 | 推断、预测或跨模型外推 | 外源 EV 可能改善在体辐射肌损伤（尚无在体研究） |

## 两个真实课题的分级结果（供校准）

- 辐射肌损伤 v0.7：纳入 53 篇（A 15 / B 26 / C 12），所有 A 级读过全文；骨架包括 NMJ/去神经、cGAS–STING、NF-κB/STAT3、Hedgehog、c-Abl–MyoD、Myostatin、BMP–SMAD1。
- EV 干预 v0.2：纳入 141 篇（A 2 / B 120 / C 19）；唯一辐射+肌源 EV 的直接研究是体外的（PMID 40835994）。
